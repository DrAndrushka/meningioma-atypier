# 🧠 meningioma-atypier

> MRI-based prediction tool for identifying atypical meningioma patterns using radiological and histopathological data.

---

## ⚔️ Goal

Build a clinically usable prediction model for estimating atypical / higher-grade meningioma risk using MRI-derived imaging features.

The project combines:
- 🩻 neuroradiology
- 📊 statistical modeling
- 🤖 machine learning
- 🌐 Streamlit deployment

---

## 🧬 Dataset

~400 meningioma cases including:
- MRI imaging features
- WHO grading
- histopathological findings
- edema / necrosis / invasion patterns
- ADC / DWI characteristics
- tumor size & localization

---

## 🛠️ Pipeline

- clean & structure clinical data
- exploratory analysis
- logistic regression
- random forest
- gradient boosting
- model validation
- Streamlit calculator deployment

---

## 📈 Planned Outputs

- atypical meningioma risk estimation
- clinician-friendly MRI calculator
- ROC/AUC evaluation
- interpretable prediction scoring

---

## ⚡ Philosophy

Clean data before clever AI.

Clinical usefulness before hype.
