# ───────────────────────────────────────────────────────────────────────────────
# 📊 Core analysis pipeline
#    cleaning → schema → DDA → EDA → diagnostic accuracy → MICE →
#    multivariable logistic (literature + experimental variants) →
#    bootstrap validation → performance figures → HTML report
# ───────────────────────────────────────────────────────────────────────────────

pandas>=2.2,<4
# Tabular data: cohort loading, schema application, CSV/Excel I/O, pipeline tables.

numpy>=2.0,<3
# Numeric arrays underpinning stats, design matrices, and imputation.

scipy>=1.11
# Classical tests (Mann–Whitney, χ², Fisher, skew/kurtosis), calibration root-finding,
# and the figure maths in plot_style.py — confidence intervals for percentages
# (Wilson) and the smooth curves drawn over histograms.

statsmodels>=0.14
# Multivariable logistic regression (Logit), VIF, Wilson-style proportion CIs, calibration,
# and the LOESS trend lines used wherever a figure shows a relationship without
# assuming it is a straight line (DDA scatter plots, EDA, calibration curves).

scikit-learn>=1.4
# RF chained imputation sensitivity method (IterativeImputer + RandomForestRegressor)
# and ROC/AUC/Brier metrics (diagnostic accuracy in eda.py + bootstrap validation in
# model_validation.py). Formal MICE itself runs in R, not sklearn.

joblib>=1.3
# Parallel RF sensitivity-imputation draws (missingness_resolution.py).

matplotlib>=3.8
# Every figure the pipeline exports: distribution and comparison plots (DDA),
# association plots (EDA), forest plots, and the model-performance figures
# (ROC, calibration, decision curve, model comparison). All go through the one
# shared style in modelling_phase/plot_style.py.

SciencePlots>=2.1
# Publication matplotlib styles for every pipeline figure (`science` + `nature` + `no-latex`).

seaborn>=0.13
# Heatmaps only — the EDA association overview, the per-pair share tables, and
# the missingness overlap map. Other figures are drawn directly on matplotlib
# so their statistics (intervals, denominators) are explicit rather than implied.
openpyxl>=3.1
# Read Excel cohort exports when the raw file is .xlsx (CSV also supported).

pyarrow>=15.0
# Parquet I/O for dataset handoff and MICE imputation draws.

pandera>=0.20
# Schema validation (dtypes, categories, ranges) of the cleaned cohort and of
# every MICE-imputed frame. Uses the `pandera.pandas` namespace (added in 0.20).

python-docx>=1.1
# Submission-ready Word tables from the cut-point phase. The journal's rules are
# enforced in code rather than by eye: every border element stripped from the
# table XML, total width asserted under 6.5 in so the table cannot be set
# broadside, and a `Note:—` footnote written directly beneath each table.
