# ⚠️ NON-PYTHON DEPENDENCY — formal MICE (proper_mice_impute) runs the R `mice`

# One-time setup:
#   1. Install R         (macOS: `brew install r`, or https://cran.r-project.org)
#   2. Install packages: Rscript -e 'install.packages(c("mice","jsonlite"))'
# Tested with: R 4.6.1, mice 3.19.0, jsonlite 2.0.0
# Minimum:     R >= 4.1, mice >= 3.16, jsonlite >= 1.8
# (the exact versions of each run are recorded in output/missingness/mice/r_session.json)
# The pure-Python RF sensitivity method (rf_chained_impute) needs no R.
#
# Notebooks (run from repo root — same folder as app.py):
#   jupyter notebook meningioma-cleaning.ipynb
#   jupyter notebook meningioma-modelling.ipynb
#
# Tests (repo root):
#   python -m pytest
# Tests (heavy_machinery/):
#   cd heavy_machinery && python -m pytest
#
# Calculator:
#   streamlit run app.py

pandas>=2.2,<4
# Tabular data: cohort loading, schema application, CSV/Excel I/O, pipeline tables.

numpy>=2.0,<3
# Numeric arrays underpinning stats, design matrices, and imputation.

scipy>=1.11
# Classical tests (Mann–Whitney, χ², Fisher, skew/kurtosis) and calibration root-finding.

statsmodels>=0.14
# Multivariable logistic regression (Logit), VIF, Wilson-style proportion CIs, calibration,
# and DDA trivariate LOESS smooths (nonparametric.smoothers_lowess).

scikit-learn>=1.4
# RF chained imputation sensitivity method (IterativeImputer + RandomForestRegressor)
# and ROC/AUC/Brier metrics (diagnostic accuracy in eda.py + bootstrap validation in
# model_validation.py). Formal MICE itself runs in R, not sklearn.

joblib>=1.3
# Parallel RF sensitivity-imputation draws (missingness_resolution.py).

matplotlib>=3.8
# Distribution plots (DDA), forest plots, validation charts, missingness bars.

SciencePlots>=2.1
# Publication matplotlib styles for DDA trivariate figures (`science` + `no-latex`).

seaborn>=0.13
# EDA association plots, missingness heatmaps, and DDA bivariate figures.
openpyxl>=3.1
# Read Excel cohort exports when the raw file is .xlsx (CSV also supported).

pyarrow>=15.0
# Parquet I/O for dataset handoff and MICE imputation draws.

pandera>=0.20
# Schema validation (dtypes, categories, ranges) of the cleaned cohort and of
# every MICE-imputed frame. Uses the `pandera.pandas` namespace (added in 0.20).
